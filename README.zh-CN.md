# Cadenza · 琴瀑

一个浏览器里的“钢琴块”式节奏游戏：点下落的黑块，每点一下就用合成钢琴弹出公有领域曲目的下一个音。

**在线试玩：https://appleweiping.github.io/cadenza/**（手机也能玩）

## 操作

| 动作 | 触屏 / 鼠标 | 键盘 |
|---|---|---|
| 点方块 | 点它 | `D` `F` `J` `K` 对应四条轨道 |
| 长按块 | 按住直到结束 | 按住对应键 |
| 双押块（同一排两个） | 两条轨道一起点 | 两个键一起按 |
| 暂停 | 右上角暂停按钮 | `Esc` |
| 切换语言 | 菜单顶栏的 `EN` / `中文` 按钮 | |

点到空白轨道或让方块滑出屏幕底部即失败（每局可免费复活一次）。判定按点击时方块的位置分 PERFECT / GREAT / GOOD。弹完一遍得一顶皇冠，下一圈提速 16%；三顶皇冠之后会一直加速，直到失误。

首次打开时语言跟随浏览器（浏览器是中文就显示中文，否则英文），顶栏按钮切换后会记住你的选择。

## 谱面怎么写

没有伴奏音轨，声音全部由点击触发：每个方块带着自己要弹的音，滚动速度由曲子的 BPM 决定。所以一首歌就是一段用简单记号写成的旋律：

```js
{
  id: 'my-song', collection: 'baroque', difficulty: 3, bpm: 96,
  title: { zh: '我的歌', en: 'My Song' },
  composer: 'J. S. Bach',
  score: `
    E5/8 D#5/16 E5/16 | A4/2~ | (C4,E4)/4 [C4+E4]/4 r/8 G4/8t
  `,
}
```

| 记号 | 含义 |
|---|---|
| `E5/8` | 一个方块，音高 E5，八分音符。`/1` 是全音符（4 拍），最短到 `/32` |
| `/4.`、`/8t` | 附点（×1.5）、三连音（×⅔） |
| `A4/2~` | 长按块：按住 2 拍拿额外分 |
| `(C4,E4)/4` | 和弦：一个方块奏多个音 |
| `[C4+E4]/4` | 双押：同一排两个方块，各奏一个音 |
| `r/8` | 休止：在前一个方块后留空 |
| `\|` | 小节线，解析时忽略 |

轨道由“歌曲 id + 圈数”作种子的随机数生成：同一圈图案固定、可以练，换一圈就不一样；相邻两个方块不会落在同一轨。

曲库共 167 首、14 张专辑、9,222 个方块（数字来自 `node tools/validate-charts.mjs` 的输出）。谱面是按旋律手写的简化单线编配，没有逐音对照出版乐谱核对，难免有简化和个别错音，欢迎指正。

## 加一首歌

1. 在 `js/data/songs/` 里对应专辑的文件中加一个上面那样的对象（专辑列表在 `js/data/collections.js`）。
2. 运行 `node tools/validate-charts.mjs`，它会编译所有谱面并检查音名、时值、长度下限、双押比例、id 唯一和专辑引用。CI 在每次 push 和每次部署 Pages 前都会跑它。
3. 刷新页面即可在专辑里看到新歌。

只收传统民谣或作曲家去世超过 70 年的作品，并在 `composer` 字段写明作曲家。

## 本地运行

```bash
git clone https://github.com/appleweiping/cadenza.git
cd cadenza
python -m http.server 8144     # 然后打开 http://localhost:8144
```

用了 ES 模块，所以需要本地服务器，不能直接用 `file://` 打开。没有依赖，也没有构建步骤。
